# 💫 About Me:
- 🔭 I'm currently working on an **AI voice sales agent**, an outbound U.S. English voice assistant for a client in the insurance space. It qualifies leads, answers only from an approved knowledge base, and hands interested prospects to a licensed human over a live call transfer. It runs on **Python, FastAPI, Pipecat, Telnyx, Deepgram, Cartesia and OpenAI**, with **PostgreSQL (pgvector), Redis and Docker** behind it.<br>- 👯 I'm looking to collaborate on **conversational AI / voice agents**, **full-stack web projects (React, Node.js, MongoDB)**, and open-source projects.<br>- 🤝 I'm looking for help with **compliance-aware AI design**, **latency tuning for real-time voice**, **CI/CD pipelines**, and **test automation / SQA**.<br>- 🌱 I'm currently learning **real-time voice AI pipelines (STT → LLM → TTS)**, **RAG with pgvector**, **cloud (AWS, Azure)**, **GitHub Actions** and **DevOps**.<br>- 💬 Ask me about **voice agent design**, **safe AI call handoff to humans**, **MERN stack development**, **Gemini-powered virtual try-on (Shirtify)**, **caching ML forecasts (8s → under 50ms)** or **Android development**.<br>- ⚡ Fun fact: I've built an AI that tries T-shirts on you (Shirtify), and now one that makes phone calls. 📞
